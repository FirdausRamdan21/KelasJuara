# Training-01: Kumpulan Tugas Front-End

Repositori ini berisi kumpulan latihan front-end berbasis **HTML**, **CSS**, dan **JavaScript** dengan tingkat kesulitan **Easy** dan **Medium**. Setiap soal memiliki template siap pakai dan fokus pada pemahaman DOM serta interaksi halaman web.

## 🧩 Daftar Soal

### 🟢 Easy
| Kode | Judul | Konsep |
|------|-------|--------|
| E1 | Sapa Dunia | `getElementById`, `addEventListener`, `innerText` |
| E2 | Ganti Nama | Mengubah isi elemen |
| E3 | Hitung Klik | Variabel, event klik |
| E4 | Warna Teks | `.style.color` |
| E5 | Toggle Sederhana | `if else` |

### 🟡 Medium
| Kode | Judul | Konsep |
|------|-------|--------|
| M1 | Toggle Teks | Kondisi bolak-balik |
| M2 | Validasi Input Nama | `.value`, validasi kosong |
| M3 | Penghitung Mundur | Decrement, `.disabled` |
| M4 | Ubah Tema Halaman | `document.body.style` |
| M5 | Kalkulator Tambah | `Number()` |
| M6 | Tebak Angka | Perbandingan nilai |
| M7 | Ubah Ukuran Teks | `.style.fontSize`, batas minimum |

---

## 🚀 Cara Menjalankan

1. Buka folder soal yang diinginkan.
2. Jalankan file `index.html` di browser.
3. Baca instruksi di dalam file.
4. Tuliskan JavaScript pada bagian yang sudah disediakan.
5. Simpan dan muat ulang halaman untuk menguji.

---

## 🛠️ Teknologi

- HTML5

## ✅ Tujuan Pembelajaran

- Memahami DOM dan cara mengakses elemen.
- Menerapkan event handling.
- Mengubah konten dan gaya secara dinamis.
- Melatih logika percabangan dan variabel.

---

## 📌 Catatan

- Jangan mengubah bagian HTML.
- Kerjakan pada bagian `<script>` yang tersedia.
- Gunakan fitur browser untuk melihat hasil.
