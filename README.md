# ⚡ JavaScript DOM Mastery: EASY & Medium Series

A comprehensive collection of **15 hands-on JavaScript exercises** covering fundamental DOM manipulation, event handling, conditional logic, and creative problem-solving—built entirely with Vanilla JS.

> *From basic interactions to intermediate logic challenges, this repository showcases my structured approach to learning: build the logic first, write the code second.*

---

## 📂 Project Overview

This repository is divided into **two main series**, each targeting specific skill levels:

| Series | Focus | Number of Projects |
|:-------|:------|:------------------:|
| **EASY Series** | Core DOM properties & creative experimentation | 8 |
| **Medium Series** | Conditional logic, validation & interactive mechanics | 7 |

---

## 🟢 EASY Series (Foundation & Creativity)

These projects focus on mastering essential DOM properties and event handlers, with a touch of creative freedom.

| # | Project Name | Functionality | Key Concept |
|:--:|--------------|---------------|-------------|
| 1 | **EASY1-HELLO** | Displays "Hello World" with an interactive link | `innerText`, `addEventListener` |
| 2 | **EASY2-NAMA** | Dynamically changes a name inside a paragraph | `.value`, DOM updates |
| 3 | **EASY3-CLICK** | Increments a number on every button click | Variable state (`let`), event listeners |
| 4 | **EASY4-Sembunyikan..?** | Toggles visibility of a hidden element | `style.display`, conditional logic |
| 5 | **EASY5-COLOR** | Changes text color dynamically | `style.backgroundColor`, interaction |
| 6 | **EASY6-paragraf** | Modifies paragraph content via user input | `innerHTML`, DOM replacement |
| 7 | **EASY7-TANGGAL** | Displays and formats the current date | JavaScript `Date` object |
| 8 | **EASY8-bug...?** | Creative debugging / experimental feature | Problem-solving, creative coding |

---

## 🟡 Medium Series (Logic & Validation)

These projects dive deeper into conditional logic, user input validation, and interactive game mechanics.

| # | Project Name | Functionality | Key Concept |
|:--:|--------------|---------------|-------------|
| 1 | **Toggle Teks** | Shows/hides text on button click | `if-else`, `innerText`, `addEventListener` |
| 2 | **Validasi Input Nama** | Validates user name input with feedback | `.value`, `if-else`, `innerText` |
| 3 | **Penghitung Mundur** | Countdown timer with disabled button control | `let`, decrement operator, `.disabled` |
| 4 | **Ubah Tema Halaman** | Switches page background theme | `document.body.style.backgroundColor` |
| 5 | **Kalkulator Tambah** | Simple addition calculator | `Number()`, `.value`, `innerText` |
| 6 | **Tebak Angka** | Number guessing game with validation | `===`, `Number()`, input validation |
| 7 | **Ubah Ukuran Teks** | Adjusts text size with min/max limits | `.style.fontSize`, boundary conditions |

---

## 🧰 Technologies Used

- **HTML5** – Page structure
- **CSS3** – Basic styling
- **JavaScript (Vanilla)** – All DOM interactions, logic, and event handling

*No external libraries or frameworks are used—everything is pure, native JavaScript.*

## 🚀 How to Run

1. **Clone** this repository to your local machine.
2. Navigate to either the `EASY-Series/` or `Medium-Series/` folder.
3. Open any `index.html` (for EASY) or `.html` file (for Medium) directly in your web browser.
4. No server, dependencies, or installations required—**everything runs locally**.
